# Honorine Iduhorahafi — Personal Portfolio

This is a responsive GitHub Pages portfolio for Honorine Iduhorahafi.

## Files
- `index.html` — main portfolio page
- `style.css` — design and responsive layout
- `script.js` — mobile menu + light/dark mode
- `assets/profile.jpeg` — profile picture
- `assets/Honorine_Iduhorahafi_CV.pdf` — two-page CV

## Publish with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new repository named `honorine-portfolio` (or any name you like).
3. Upload **all files and folders** from this project.
4. Open the repository → **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/ (root)**.
7. Click **Save**.
8. Wait a few minutes. GitHub will show your live portfolio URL.

Important: keep `index.html` in the repository root, and keep the `assets` folder beside it. The CV button works because the PDF is stored at `assets/Honorine_Iduhorahafi_CV.pdf`.
